# Food Ordering App (Android)

A simple Android application that allows users to browse food items, add them to a cart, and place basic orders.  
Built to demonstrate Android development fundamentals and UI interactions.

---

## 🚀 Features

- Browse food menu
- Add items to cart
- Remove items from cart
- View total price
- Simple order flow

---

## 🛠️ Tech Stack

- Java  
- Android Studio  
- XML (Layouts)  
- Gradle  

---

## 📦 How to Run

1. Open the project in Android Studio  
2. Let Gradle sync complete  
3. Run on an emulator or physical Android device  

---

## 📌 Notes

This project focuses on demonstrating core Android concepts such as activities, adapters, layouts, and basic data handling.
